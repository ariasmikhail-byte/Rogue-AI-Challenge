# CMP 131 – Rogue AI Shutdown Challenge

An experimental AI system is behaving unpredictably. Your team must build and test a Python diagnostic program before the system becomes unstable.

## Start Here

Read [Rogue-AI-Challenge.md](Rogue-AI-Challenge.md) completely before writing code.

## Required Files

- `rogue_ai.py` — your team's program
- `TEST-LOG.md` — predictions and test results
- `AI-Use-Report.md` — brief record of any AI assistance

Keep the Python file in the repository root.

## Team Roles

- **Driver:** Types the team's agreed-upon code.
- **Logic Checker:** Checks conditions, operators, and indentation.
- **Test Engineer:** Records predictions and test results.
- **Reporter:** Explains the team's decisions and one debugging result.

Rotate roles if time permits. Every team member must be able to explain the program.

## Workflow

1. One team member creates the team's repository from this template and shares it with the team.
2. Clone the team repository and open the entire folder in Visual Studio Code.
3. Read the challenge before editing `rogue_ai.py`.
4. Complete Levels 1–3 in order.
5. Ask the course AI assistant to test—not write—your program.
6. After the required tests pass, unlock the Random AI Attack and let Copilot simulate one surprise scenario.
7. Record predictions and results in `TEST-LOG.md`.
8. Commit and push the team's work.
9. Verify the files on GitHub.
10. Prepare a one-minute demonstration.

**Do not push student work to the instructor's starter repository.**
