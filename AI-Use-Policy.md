# CMP 131 – Artificial Intelligence Use Policy

AI tools, including GitHub Copilot and ChatGPT, may be used as learning assistants in this course. They must support your learning rather than replace your thinking and programming.

## Permitted Uses

You may use an AI tool to:

- explain a Python concept in simpler language;
- explain syntax and runtime errors;
- provide one small hint or guiding question;
- help identify a problem in code you already wrote;
- suggest test cases and boundary values;
- ask you to predict output before running code;
- review a plan or explain lecture material.

## Prohibited Uses

You may not use an AI tool to:

- generate a complete or partial solution to a challenge or assignment;
- directly edit or replace your graded Python program;
- provide copy-ready conditions or required output;
- complete the test log or AI-use report for you;
- submit AI-generated code you cannot explain;
- use AI during a quiz or exam unless explicitly permitted.

## Student Responsibility

You are responsible for every line of submitted code. You must be able to explain what each condition tests, why each operator was selected, which path runs, and how the team tested the program.

## Required AI-Use Report

If the team uses an AI tool, complete `AI-Use-Report.md`. Record what help was requested, how the team evaluated it, and what was learned. If no AI was used, say so in the report.

AI assistance must follow the course academic-integrity policy. Ask the instructor when uncertain whether a use is permitted.
